# 使用指南

[文档导航](README.md) · [下载安装与快速上手](../README.md) · [外部 Agent / MCP](mcp.md)

本文说明已安装应用的日常操作；无需安装 Flutter 或 Xcode。

## 终端与工作区

当前发行包支持 macOS / Apple Silicon。启动时显示空工作区，不自动创建标签页或 shell。点击「新建终端」后启动登录 shell（Windows 为 PowerShell），工作目录为用户 HOME。支持 ANSI、中文、交互程序、键盘输入、窗口尺寸同步和 Ctrl+C。内置等宽 Nerd Fonts Symbols 回退字体，支持 agnoster 等 zsh 主题的 Powerline / Nerd Font 图标，无需额外安装系统字体。关闭 app 会向终端和 agent 进程发送终止信号；自行脱离会话的后台进程可能继续运行。

## 快捷键与布局

使用紧凑的 mac 风格控件、原生 macOS「终端」菜单和设置弹窗。⌘T 新建终端、⌘W 关闭当前标签页、⌘, 打开设置、⌘⌥←/→ 切换终端；⌘⇧A 聚焦 Agent，⌘Return 发送任务，普通 Enter 换行。侧栏支持右键操作、双击/F2 改名；分隔条支持拖动、聚焦后方向键调整、Home/双击恢复。终端接入标准文本输入法通道。

## 多终端、SSH 与会话绑定

左侧 `New` 新建 shell，点击 Tab 切换，双击或长按名称改名，关闭按钮终止对应会话。终端支持选中后复制、通过右键菜单粘贴，沿用 xterm 的平台键盘快捷键。Tab 的 `terminal-N` 是本次运行中的稳定 ID，关闭后不复用。

在左下角「SSH 设置」中添加入口，随后从 New 旁的下拉菜单打开。支持用户名、端口、默认 `~/.ssh/id_rsa` 或自定义密钥路径，以及密码登录。macOS 可在设置中填写密码并保存到系统钥匙串，连接时自动读取；留空则在终端手动输入，清空后保存可移除已存密码。其他平台仍在终端输入密码；保留系统 OpenSSH 的主机指纹确认。自动设置 `ServerAliveInterval=30` 与 `ServerAliveCountMax=3`。SSH 可执行程序需已在系统 PATH 中。

Agent 内容区与输入区之间的工具栏可将当前会话绑定到激活的 Tab，已绑定时提供解绑按钮；无激活 Tab 时不能绑定。绑定严格一对一，新建绑定前先解除双方原有绑定。终端 Tab 右键菜单也可管理绑定。切换到有绑定的 Tab 时自动显示对应会话，未绑定的 Tab 保留当前会话。手动切换会话不会更改已有绑定。关闭终端或退出程序会解除绑定并保留会话，删除会话自动解除其所有绑定。Tab 目前不跨重启恢复，绑定随当前 Tab 生命周期生效。

## 模型、Skills 与执行审批

1. 在设置中添加一个或多个 LLM 配置，填写服务地址（如 `https://host`，默认使用 `/v1`）或 API 基础地址（如 `https://host/gateway/v1`），也可填写标准完整请求地址。每组 Endpoint 和 API Key 只需配置一次。点击「从 API 加载模型」后保存，或每行手填一个模型 ID。所有已保存的模型都可在右侧按消息选择。
2. 支持 **OpenAI-compatible Chat Completions**（例如 `https://host/v1/chat/completions`）和 **Anthropic Messages**（例如 `https://host/v1/messages`）。认证支持 Bearer、`x-api-key` 或无认证。要求模型支持工具调用。主对话与风险评估均发送 `stream: true` 接收 SSE，正文逐步显示；工具参数在收到完整完成事件后才解析并执行。兼容仍返回普通 JSON 的服务。
3. 可填写 Skills 根目录（支持 `~/`）。任务开始时递归发现 `SKILL.md`，将名称和描述提供给模型；模型通过 `skill_read` 按需读取全文。最多 200 个 Skill，单文件最多 128 KiB，不跟随目录符号链接，不允许读取根目录外的文件。Skill 附属脚本可由模型根据指引通过已授权的终端调用。
4. 在右侧底部选择模型、填写任务并点击「发送」。会话保留上下文，右上角可新建会话，或从「Agent 会话历史」搜索、切换、重命名和删除历史会话。每个会话独立保存草稿，切换时运行中的任务仍在原会话继续。任务绑定开始时选中的终端，最多 40 轮；工具调用和回复显示在日志中。关闭目标 Tab 后任务停止。点击「停止」会停止后续工具调用；已提交的 shell 命令可用终端 Ctrl+C 中断。

配置保存在 `~/.terminal-use/settings.json`（Windows 使用 `%APPDATA%/.terminal-use/settings.json`），Unix 目录权限 700、文件权限 600。API Key 保存在此本地文件中，输入界面隐藏显示。终端内容与 Skills 会发送给用户配置的模型 Endpoint；请求诊断追踪不单独写入历史文件。SSH 密码在 macOS 存入系统钥匙串，不写入配置文件。Agent 消息、工具记录、风险审批记录、上下文和草稿自动保存到同目录的 `agent-history.json`（Unix 权限 600），重启后可继续历史会话；未完成的任务和审批不会自动恢复执行。读取失败时保留原文件并暂停覆盖，历史入口显示错误提示。

在输入框中键入 `@` 可按 Tab 名称或 ID 选择目标。发送前无需手写 ID。

Agent 的每次终端写入（含交互按键和 Ctrl+C）都先通过当前模型的独立请求评估，再在 Agent 上下文区显示目标、原始输入、风险等级和理由。卡片分别展示命令解释和风险依据。默认三个等级均须点击「允许本次执行」才发送。在 Agent 设置中，可针对低、中、高风险分别开启自动放行，开启后匹配该等级的操作直接执行。确认卡片持续等待你决定，打开设置时也会保留。拒绝、取消操作或评估失败均不写入。外部 MCP 写入也需此确认，风险评估使用所选模型（未选择时使用首个配置），待执行输入会发送到该模型的 Endpoint。

## 权限与数据

Agent 和人工终端都具有当前用户权限。不要将 MCP 连接参数交给不受信任的客户端；App 重启后需要重新复制连接参数。风险评估模型和确认卡片不能替代系统权限隔离。

本应用在 macOS 关闭 App Sandbox，以支持本地 shell；发行渠道是签名、公证 DMG，不是 Mac App Store 沙盒应用。
配置中的 API Key 不是加密保存，Unix 文件权限仅限制其他系统用户。历史文件也可能含终端输出和业务文本；不要直接上传到 Issue。
模型服务会收到任务所需的对话、终端输出及 Skills 内容；使用前确认你愿意向该服务发送这些数据。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 启动后没有终端 | 这是正常空工作区，点击“新建终端”。 |
| 模型无法运行 | 检查服务地址、认证、模型 ID 和工具调用支持；模型服务需要自行配置。 |
| 命令一直未执行 | 检查是否有等待决定的风险卡片，选择允许或拒绝。 |
| 停止 Agent 后命令仍在运行 | “停止”终止后续 Agent 操作；已提交的命令可在目标终端按 Ctrl+C。 |
| 重新打开 App 后终端或绑定消失 | 终端 Tab 和绑定不跨重启恢复；Agent 历史会话会保存。 |
| 关闭 App 后仍有进程 | `nohup` 或自行脱离会话的后台进程可能继续运行。 |
| 历史记录提示读取失败 | 应用保留原文件并暂停覆盖；先备份文件，再提供已脱敏的错误信息。 |
| 外部 Agent 无法连接 | 检查 Python 3、App 是否运行、连接参数是否属于当前启动，见 [MCP 接入](mcp.md)。 |

反馈问题时附应用版本、macOS 版本、CPU 架构和最小复现步骤。分享截图或日志前删除令牌、密码、终端业务内容及个人路径。开发者定位日志的方法见 [诊断说明](debugging.md)。
