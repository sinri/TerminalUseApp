## 文档约定

用户操作以 [使用指南](user-guide.md) 为详细说明，README 提供快速入口；接口以 [HTTP API](http-api.md) 和 [MCP 接入](mcp.md) 为准；模块关系以 [架构](architecture.md) 为准。实施状态和公开前检查记录是带日期的记录，不应被误读为最新提交已经完成的验证。

变更行为时同时更新对应文档，通过链接引用同一主题，避免在 README 重复维护工具链和协议细节。凭据、真实终端输出和私人路径不得用于示例。维护步骤见 [开发指南](development.md#文档维护)。
