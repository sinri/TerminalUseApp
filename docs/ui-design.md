# Terminal Use 桌面界面规范

[文档导航](README.md)

方向：紧凑的 macOS 工具工作区。保留 Flutter 和现有三栏结构，不增加顶部工作区标题栏；使用中性面板、系统字体、细分隔线和蓝色焦点。启动为空工作区，由用户创建本地或 SSH 终端。

## 共享控件

`lib/src/mac_controls.dart` 包含统一的 MacButton、MacPopup、MacSection、MacSplitHandle 和 MacSidebarItem。它们建立在 Flutter 的按钮、SubmenuButton、焦点、动作和语义机制上，保留键盘可操作性；控件仍由 Flutter 绘制。macOS 的应用菜单、终端菜单、快捷键入口和窗口标题由 AppKit 提供。

- 按钮通常高 26px，圆角 5px；普通按钮使用中性边框，主要操作使用强调色。悬停、按下和禁用状态明确，焦点使用蓝色边框，不显示 Material 水波纹。
- 菜单使用紧凑行高，支持方向键、Enter 选择与 Escape 取消。长模型名称在主控件中省略，菜单显示更长的名称。
- 侧栏默认宽 180px；条目按下即选中，双击或 F2 改名，右键提供重命名和关闭。关闭按钮位于名称双击区域之外，避免关闭等待双击判定。
- 分隔条保留 6px 水平拖动区/8px 垂直拖动区，悬停和聚焦高亮。点击聚焦后用方向键调整，Home 或双击恢复默认尺寸；辅助功能提供增减动作。
- 底部状态栏约 22px。空工作区跟随主题，打开后的终端画布保持深色，保证 ANSI 颜色稳定。

## 键盘和输入

| 操作 | macOS 快捷键 |
| --- | --- |
| 新建终端 | ⌘T |
| 关闭当前终端；设置中关闭弹窗；无终端时关闭窗口 | ⌘W |
| Agent 设置 | ⌘, |
| 上一个/下一个终端 | ⌘⌥← / ⌘⌥→ |
| 聚焦 Agent 输入 | ⌘⇧A |
| 发送任务（普通 Enter 换行） | ⌘Return |
| 停止 Agent 后续操作（输入区聚焦时） | ⌘. |
| 关闭菜单/设置/编辑弹窗 | Escape |

切换或新建终端后聚焦终端。终端使用标准文本输入通道，输入法组合阶段只绘制候选文本，提交后才发送至 PTY。终端保留 Menlo 与 Nerd Fonts 回退。Agent 也不会在文本组合尚未完成时提交任务。

系统编辑菜单的复制、粘贴和全选按当前焦点路由：终端使用终端选区与 PTY，Agent 和设置使用 Flutter 文本框的编辑状态。没有匹配焦点时交还 AppKit 响应链。

## 设置与 Agent

设置是保留工作区背景的居中模态弹窗，Agent/SSH 使用分段选择器切换。配置按模型服务、命令放行、Skills 和 MCP 分组。编辑表单首字段自动聚焦，单行字段 Return 或 ⌘Return 可提交，验证失败时保留输入并滚动到错误；Escape 取消。删除配置提供明确确认。保存 Skills 和复制连接参数均提供结果反馈。

Agent 的空状态位于内容区上方，正文与输入区使用分隔线划分。目标终端显示在输入框外，模型选择与发送操作在底部同一行。正在等待的风险卡片保留在上下文中；打开设置后，模态遮罩阻止误操作。

## 关于窗口

菜单栏与窗口标题统一为 `Terminal Use APP`。原生应用菜单的“关于”打开 Flutter 弹窗，显示包内版本、作者、GitHub 项目及 GPL v3.0 信息，提供项目链接和完整许可证列表。许可证列表包含本项目、Flutter 收集的依赖许可和 Nerd Fonts 文本；项目版本从 macOS Bundle 元数据读取。

## 验证范围

控件测试覆盖键盘激活、禁用状态、菜单选择与取消、分隔条键盘调整、侧栏选中语义、窄工具栏、长模型名称、深浅主题切换、放大字体和减少动态效果下的设置表单。macOS 集成测试覆盖空工作区、中文组合输入提交、系统编辑菜单的剪贴板路由、拖动分栏、设置开关、风险确认与真实 PTY。

UI UX Pro Max 用于交互规则参考；没有采用其网页首页布局、光标特效或移动端触控尺寸作为桌面设计要求。当前任务不涉及 Flutter SDK 升级或修改。
