# Desktop icons

Artwork was created with the built-in imagegen tool. Production prompt: graphite
blue-black tile (#20252D), rounded terminal chevron (#66D9EF), tilted four-point
AI sparkle (#66D9EF → #8BE9C1), underscore mouth (#77D6B0), transparent exterior,
restrained satin finish. Tray prompt: the same face without the tile, bold shapes
for 16–32 px. Generated colors are visual approximations of these target colors.

Regenerate macOS/Windows icons with `dart run flutter_launcher_icons` using the
root `flutter_launcher_icons.yaml` config. Regenerate Linux and tray exports with
`python3 tools/generate_desktop_icons.py` (Pillow required).
The app master is `assets/icons/app-icon-source.png`; the tray master is here.

- macOS: all existing AppIcon asset catalog sizes are replaced.
- Windows: `windows/runner/resources/app_icon.ico` is generated by Flutter Launcher Icons and
  is already referenced by Runner.rc for the executable/window icon.
- Tray: `assets/icons/tray_icon.ico` and `tray_icon_{size}.png` are bundled Flutter
  assets. There is no tray controller in the app yet; these are ready-to-use
  resources, not a new background/minimize-to-tray feature. Native tray APIs need
  a real filesystem path; extract the asset first when adding a tray controller.
- Linux: the window loads `data/app_icon.png` relative to the executable. CMake
  also bundles the desktop entry and hicolor icon. For system launcher integration,
  install the desktop entry under `~/.local/share/applications`, its icon under
  `~/.local/share/icons/hicolor/512x512/apps`, and ensure `terminal_use_app` is in
  PATH (or set the desktop entry's Exec to the installed binary's absolute path).

Windows and Linux native builds must be checked on their corresponding hosts.
